# US-044 OEM Mode demo

Open `/?source=manual`, press the wrench (setup), pick X, scroll ▼ to `EnF on` (press ▶ once) — that's your custom setting. Press C to exit, re-enter setup, pick X, scroll ▼ to `oEm mod`, press ENT → `PASS`; type `3 5 7 2 6`, press ENT → `oEm` (you're in OEM Mode), press ENT → `StorEd` (current config stored as the OEM baseline, EnF on included). Reload the page → the baseline persists in localStorage (`nvMem.oemDefaults`). Wrong code path: at `PASS`, type `0 0 0 0`, press ENT → `Err` flashes and returns to `oEm mod` — OEM Mode is never entered.
